# StudentSwap 🔄

**«Обменяйся с теми, кто рядом. Вещи, конспекты, навыки — всё по-студенчески.»**

Telegram Mini App для студентов Санкт-Петербурга: обмен, отдача и поиск вещей,
учебных материалов и навыков внутри студенческого коммьюнити.

## Возможности (MVP)

- Объявления по категориям с подкатегориями:
  **Вещи** (одежда, техника, мебель, посуда, спорт-инвентарь, книги, канцелярия, другое),
  **Учебные материалы** (конспекты, лабораторные, курсовые, презентации, д/з, другое),
  **Навыки** (репетиторство, программирование, дизайн, иностранные языки, монтаж видео, печать, настройка техники, другое),
  **Покупки** (еда, билеты, подписки, бытовая химия)
- Раздел «Хочу» — запросы (ищу вещь/услугу); при появлении подходящего предложения автор запроса получает уведомление
- Поиск и фильтры на одной панели: ключевые слова, категории с подкатегориями,
  тип сделки, формат (офлайн/онлайн), радиус (1 / 3 / 5 / 10 км), сортировка «ближе ко мне»
- Фильтр по учебному заведению: 30+ вузов и 14 колледжей СПб с поиском по названию
- Геокарта на **Яндекс Картах** с метками кампусов и объявлений
- До 10 фото на объявление
- Верификация двумя способами: по почте вуза (код письмом через SMTP) или
  **по фото студенческого билета** (заявку проверяет администратор);
  без подтверждения можно разместить только одно объявление
- Отзывы и рейтинг после сделки + баллы доверия обеим сторонам
- Избранное, уведомления («Твоё объявление просмотрели N раз» и др.):
  колокольчик в шапке меняется и «звенит» при новых (фоновая проверка каждые
  30 сек), плюс дублирование пуш-сообщением в личку через бота (Bot API
  `sendMessage`; работает при заданном `BOT_TOKEN`, если пользователь нажимал
  Start у бота)
- Связь через личку Telegram (кнопка «Написать в Telegram»)
- Тёплый дизайн (крем/терракота/мёд), контурные SVG-иконки,
  автоматическая тёмная/светлая тема из Telegram

## Быстрый старт (локально)

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate          # Windows  (Linux/macOS: source .venv/bin/activate)
pip install -r requirements.txt
copy .env.example .env          # DEV_MODE=1 уже включён
python -m uvicorn app.main:app --reload
```

Открой **http://localhost:8000/app/** — в браузере без Telegram работает
dev-режим с тестовым пользователем и демо-объявлениями.
База — SQLite-файл `backend/studentswap.db`, создаётся автоматически.

Код подтверждения почты в dev-режиме печатается в консоль сервера
(если SMTP не настроен).

## Отправка писем (SMTP)

Коды верификации отправляются реальными письмами, как только в `backend/.env`
заполнен SMTP. Для Gmail: включи двухфакторную аутентификацию и создай
«Пароль приложения» (myaccount.google.com → Безопасность → Пароли приложений):

```
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=airjordaniel28@gmail.com
SMTP_PASSWORD=пароль-приложения-из-16-символов
SMTP_FROM=airjordaniel28@gmail.com
```

Для Яндекс Почты: `SMTP_HOST=smtp.yandex.ru`, `SMTP_PORT=465`, `SMTP_SSL=1`
(и тоже пароль приложения). Если SMTP не настроен: в `DEV_MODE=1` код падает
в лог сервера, в проде запрос вернёт ошибку 503.

Ограничение: неподтверждённый пользователь может держать только **одно активное
объявление** — при попытке создать второе API вернёт 403, а приложение покажет
окно с предложением подтвердить почту вуза.

## Админ-панель

Отдельной кнопки входа нет. Вход скрытый: профиль → строка статуса верификации
(«Почта вуза не подтверждена» / «Студент подтверждён») → в форме подтверждения
ввести **email администратора** — форма переключится на запрос пароля.
Email и пароль задаются в `backend/.env` (`ADMIN_EMAIL`, `ADMIN_PASSWORD`;
пустой пароль = админка выключена).
Возможности:
- **Проверка заявок по студбилету** — очередь фото в начале админ-панели,
  кнопки «Одобрить/Отклонить», пользователь получает уведомление;
- **Бан/разбан пользователей** — забаненный получает 403 при любом запросе,
  его объявления скрываются из ленты и поиска;
- **Удаление любых объявлений** — кнопка «Удалить как администратор» внутри
  каждого объявления.

API: `POST /api/admin/login` → подписанный токен (HMAC, срок 30 дней), далее
заголовок `X-Admin-Token` для `GET /api/admin/users?q=`, `POST /api/admin/users/{id}/ban|unban`,
`DELETE /api/admin/listings/{id}`.

## Безопасность

- `DEV_MODE=0` (боевой режим): принимается только подписанный Telegram initData;
  для локальной отладки в браузере временно поставь `DEV_MODE=1` в `backend/.env`.
- Код из письма: максимум 5 попыток ввода, после — код сгорает, нужен новый.
- Заявки на верификацию по студбилету: не больше 3 в час на пользователя.
- Фото студбилетов лежат в закрытой папке `backend/private_uploads/`
  и отдаются только по админ-токену через `/api/admin/verifications/{id}/photo`.
- Бэкапы SQLite: автоматически при старте и раз в сутки в `backend/backups/`,
  хранятся последние 14 копий (для PostgreSQL настрой `pg_dump` по cron).
- Не коммить `backend/.env` в git — там токен бота, пароль админа и SMTP-пароль.

## Яндекс Карты

Карта работает через Yandex Maps JS API 2.1. Для продакшена получите бесплатный
ключ на [developer.tech.yandex.ru](https://developer.tech.yandex.ru/) и вставьте
его в `frontend/js/app.js` → константа `YMAPS_API_KEY`. Без ключа карта
загружается в тестовом режиме с ограничениями.

## Запуск как Telegram Mini App

1. Создай бота у [@BotFather](https://t.me/BotFather), получи токен.
2. Задеплой бэкенд на HTTPS-домен (Yandex Cloud / VPS + nginx, или туннель
   `cloudflared tunnel --url http://localhost:8000` для теста).
3. В `backend/.env` пропиши `BOT_TOKEN`, `WEBAPP_URL=https://твой-домен/app/`
   и выключи dev-режим: `DEV_MODE=0`.
4. Запусти бота: `python bot.py` — он поставит кнопку меню «StudentSwap».
5. В BotFather (`/mybots → Bot Settings → Menu Button`) можно также привязать URL вручную.

## API (кратко)

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/users/me` | Профиль + счётчик уведомлений |
| PATCH | `/api/users/me` | Вуз, факультет, геоточка |
| POST | `/api/users/verify/request` / `confirm` | Верификация почтой вуза |
| GET | `/api/listings` | Поиск: `q, kind, category, subcategory, deal_type, format, university_id, max_km, sort` |
| POST | `/api/listings` | Создать объявление / запрос «Хочу» |
| POST | `/api/listings/{id}/photos` | Загрузка фото (до 10) |
| POST | `/api/listings/{id}/close` | Завершить сделку |
| POST | `/api/favorites/{id}` | Избранное (toggle) |
| POST | `/api/reviews` | Отзыв после сделки (+баллы доверия) |
| GET | `/api/notifications` | Уведомления |
| GET | `/api/meta` | Категории, подкатегории, типы и форматы сделок, вузы и колледжи |

Swagger: **http://localhost:8000/docs**

Авторизация: заголовок `Authorization: tma <initData>` (подпись проверяется
HMAC-ключом бота по алгоритму Telegram). В DEV_MODE принимается
`Authorization: dev {"id":…,"first_name":…}`.
